# Contributing to Osint Tools

Thank you for considering contributing to the Osint Tools project! We appreciate your help in improving this project. Please follow the guidelines below to ensure a smooth contribution process.

## Reporting Bugs
- When reporting a bug, please include details about the issue, steps to reproduce it, and any relevant screenshots or logs. This will help us address the issue more efficiently.

## Suggesting Enhancements
- If you have ideas for enhancements or new features, please open an issue to discuss it first. Include a clear description of the enhancement and its potential benefits.

## Code Standards
- Ensure your code follows the existing code style and conventions used in the project. Consistency helps maintain readability and quality. Common guidelines include:
  - Use meaningful variable and function names.
  - Keep the code DRY (Don't Repeat Yourself).
  - Write comments where necessary for clarity.

## Commit Messages
- Write clear and descriptive commit messages. A good commit message should:
  - Be in the present tense (e.g., "Add new feature")
  - Include a short summary of the change on the first line, followed by additional details if necessary.

## Pull Request Process
- Before submitting a pull request (PR), ensure the following:
  - Your code is tested and works as expected.
  - You have reviewed your own changes for any missed issues.
  - The PR description provides context and details about the changes.
- Once your PR is submitted, it will be reviewed, and feedback may be provided. Be open to suggestions and ready to make necessary adjustments.

Thank you for your contributions! Together, we can make Osint Tools even better!
